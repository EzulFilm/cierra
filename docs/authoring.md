# Cierra 0.1 authoring profile

For people and LLMs writing programs. Generated by tools/make_authoring.py from the op table and
cierra/examples.py; the full maths is in [spec.md](spec.md), the machine-readable table in
[ops_manifest.json](ops_manifest.json).

## Rules of thumb

- Write the whole program every time, starting with `cierra 0.1`.
- Name nodes after what they do (warm_skin, cool_shadows); one operation per node.
- Leave parameters at their defaults out; give only what you change.
- One `graph` line wires every node you want to run; nodes not in a graph do nothing (and draw a warning).
- Declare `requires depth` / `requires segments` before using depth() / segment() masks, and use only segment ids the host lists.
- grain() always needs an integer seed.
- Keep keyframes inside the clip (frames 0 .. length - 1).
- photo_to_scene() goes first in photo_graph, once, outside parallel / layer; photo_graph runs only for photo input (srgb_photo, rec1886_photo, or linear_photo when highlights were recovered above display white).
- Defaults are not always 'no change': vignette(), glow(), blur(), grain() do something with their defaults; give the values you mean.
- mix (0..1, default 1) and layer opacity (0..1, default 1) can be keyframed; layer mode defaults to normal.
- Small steps: wheel offsets of 0.005-0.02 cv, saturation 0.9-1.15, exposure within +-1 stop are typical.

## Loop

generate → parse / check → canonicalise → lint (with the host's context: clip length, planes, segment ids, targets) → render a preview → measure → revise with the diagnostics and numbers; at most N rounds; every accepted version committed with its diff.

## Examples (each passes the checker with no warnings)

### minimal: an output transform only (no graph = identity)

```
cierra 0.1
output aces2(display: srgb)
```

### serial primaries

```
cierra 0.1
name "warm, a little richer"
input linear_rec709
output aces2(display: srgb)

node balance = white_balance(temperature: 0.1)
node tone = contrast(amount: 1.05, pivot: 0.35)
node colour = saturation(amount: 1.08, protect_skin: 0.5)

graph balance -> tone -> colour
```

### masks: a skin key, and its inverse combined with a luma key

```
cierra 0.1
output aces2(display: srgb)

node skin_glow = saturation(amount: 1.12)
  label "richer skin"
  mask skin(width: 30)
node cool_shadows = wheels(lift: [-0.006, 0, 0.01])
  mask not skin() and luma(range: -0.1..0.35, soft: 0.05)
  mix 0.8

graph skin_glow -> cool_shadows
```

### hue curves and a hue qualifier that wraps through 0

```
cierra 0.1
output aces2(display: srgb)

node greens_to_gold = hue_vs_hue(points: [[206, -12, 40]])
node calm_reds = saturation(amount: 0.9)
  mask qualifier(hue: 330..30, sat: 0.02..1, soft: 0.05)

graph greens_to_gold -> calm_reds
```

### parallel (average of branches) and layer (blend)

```
cierra 0.1
output aces2(display: srgb)

node lift = exposure(stops: 0.3)
node mute = saturation(amount: 0.7)
node bright = exposure(stops: 1)
node punch = contrast(amount: 1.3)

graph parallel(lift, mute) -> layer(bright, punch, mode: multiply, opacity: 0.3)
```

### key routing: a named key, a node's key carried downstream, the outside node, the key mixer

```
cierra 0.1
output aces2(display: srgb)

# a named key: made again on the input of each node that uses it
key sky = graduated(centre: [0.5, 0.4], angle: 90, falloff: [0.1, 0.2])
# a node's own key: key(face) below is this key as it was made here, before face graded
node face = saturation(amount: 1.2)
  mask skin()
# the outside node: everything face did not select, minus half the sky (mixing or / + / - needs brackets)
node rest = saturation(amount: 0.8)
  mask not key(face) - key(sky, gain: 0.5)
node sky_cool = white_balance(temperature: -0.2)
  mask key(sky)

graph face -> rest -> sky_cool
```

### keyframes: a fade up over 24 frames, smooth

```
cierra 0.1
output aces2(display: srgb)

node fade = exposure(stops: keys(smooth, 0: -3, 24: 0))

graph fade
```

### texture with a fixed grain seed

```
cierra 0.1
output aces2(display: srgb)

node bloom = glow(threshold: 0.62, radius_px: 30, strength: 0.2)
node film_grain = grain(amount: 0.15, size_px: 1.5, seed: 1234)

graph bloom -> film_grain
```

### display-referred photo input: photo_to_scene first, in photo_graph

```
cierra 0.1
input srgb_photo
output aces2(display: srgb)

node to_scene = photo_to_scene()
node tone = contrast(amount: 1.04, pivot: 0.3)

photo_graph to_scene
graph tone
```

### depth and segment keys (the host provides the planes)

```
cierra 0.1
output aces2(display: srgb)
requires depth, segments

node far_cool = white_balance(temperature: -0.15)
  mask depth(range: 20..10000, soft: 0.2)
node person_warm = white_balance(temperature: 0.08)
  mask segment(ids: [3])

graph far_cool -> person_warm
```

## Mistakes and the checker's answer

### value out of range

```
cierra 0.1
node a = exposure(stops: 12)
graph a
```

```
program rejected:
  - line 2 node a stops: 12 is outside [-6, 6]
```

### unknown parameter

```
cierra 0.1
node a = saturation(amout: 1.1)
graph a
```

```
program rejected:
  - line 2 node a: saturation() has no parameter 'amout' (it takes: amount, protect_skin)
```

### expression instead of a number

```
cierra 0.1
node a = exposure(stops: 1 + 1)
graph a
```

```
line 2, column 28: a value is one number: no arithmetic (+, -)
```

### grain without a seed (non-deterministic)

```
cierra 0.1
node a = grain(amount: 0.2)
graph a
```

```
program rejected:
  - line 2 node a: grain() needs 'seed' (required: the random seed)
```

### depth key without declaring the plane

```
cierra 0.1
node a = exposure()
  mask depth(range: 1..5)
graph a
```

```
program rejected:
  - line 2 node a: mask depth() needs the 'depth' plane: add `requires depth`
```

### graph names a node that does not exist

```
cierra 0.1
node a = exposure(stops: 1)
graph a -> b
```

```
program rejected:
  - line 3 graph: no node named 'b'
```

### a node's key read before that node runs

```
cierra 0.1
node a = exposure(stops: 1)
  mask skin()
node b = saturation(amount: 0.5)
  mask not key(a)
graph b -> a
```

```
program rejected:
  - line 4 node b: key(a) is read before node a runs (or in the other graph): a must come before b in graph
```

### photo_to_scene outside photo_graph

```
cierra 0.1
node s = photo_to_scene()
graph s
```

```
program rejected:
  - line 3 graph: photo_to_scene() may only run in photo_graph
```

### empty hue range

```
cierra 0.1
node a = saturation(amount: 1.1)
  mask qualifier(hue: 40..40)
graph a
```

```
program rejected:
  - line 2 node a mask qualifier() hue: hue range 40..40 is empty (use 0..360 for every hue)
```

### unsorted curve points

```
cierra 0.1
node a = curve(points: [[0.6, 0.6], [0.2, 0.2]])
graph a
```

```
program rejected:
  - line 2 node a points: point x values must increase strictly (0.2 after 0.6)
```

## Operations

```
Operations:
  photo_to_scene()  [transform, pointwise] Display-referred photo (sRGB JPEG / PNG read as linear light) back to scene light through the inverse ACES 2.0 SDR sRGB output transform, so the program's ACES 2.0 output gives the photo's own placement back. Highlights roll off from knee_stops to max_stops over grey. Allowed only in photo_graph.
    recovered_highlights: bool, default True. keep stops over display white where every channel is > 1 (only linear_photo input can exceed 1; srgb_photo and rec1886_photo are clipped)
    knee_stops: num 1..10 [stops], default 4.5. roll-off start over 18 % grey
    max_stops: num 1.5..12 [stops], default 6.0. roll-off ceiling over 18 % grey
  exposure()  [primary, pointwise] Exposure: a linear-light gain (decode ACEScct, multiply by 2^stops, encode); above the toe it is the same as adding stops / 17.52, and it never lifts black below the toe.
    stops: num -6..6 [stops], default 0.0. +1 = one stop brighter
  white_balance()  [primary, pointwise] Temperature / tint as linear-light gains per AP1 channel, in stops: decode, multiply by 2^[temperature, -tint, -temperature], encode (above the toe the same as adding [...] / 17.52).
    temperature: num -2..2 [stops], default 0.0. > 0 warmer (red up, blue down)
    tint: num -2..2 [stops], default 0.0. > 0 magenta, < 0 green
  printer_lights()  [primary, pointwise] Film-lab printer points: 1 point = 0.025 log10 exposure (~1/12 stop) per channel.
    red: num -24..24 [points], default 0.0. red points
    green: num -24..24 [points], default 0.0. green points
    blue: num -24..24 [points], default 0.0. blue points
  wheels()  [primary, pointwise] Lift / gamma / gain / offset colour wheels as ACEScct offsets weighted by soft tonal ranges of luma (shadows, mids, highlights). 0.01 cv is a visible tint, 0.03 strong.
    lift: rgb each -0.3..0.3 [cv], default (0.0, 0.0, 0.0). shadow colour / level
    gamma: rgb each -0.3..0.3 [cv], default (0.0, 0.0, 0.0). mid-tone colour / level
    gain: rgb each -0.3..0.3 [cv], default (0.0, 0.0, 0.0). highlight colour / level
    offset: rgb each -0.3..0.3 [cv], default (0.0, 0.0, 0.0). whole-image colour / level
    master_lift: num -0.3..0.3 [cv], default 0.0. shadow level
    master_gamma: num -0.3..0.3 [cv], default 0.0. mid level
    master_gain: num -0.3..0.3 [cv], default 0.0. highlight level
    master_offset: num -0.3..0.3 [cv], default 0.0. overall level
  cdl()  [primary, pointwise] ASC CDL on ACEScct code values, unclamped (CLF 'FwdNoClamp'): v = in * slope + offset; v = v ** power where v >= 0; then saturation around Rec.709 luma.
    slope: rgb each 0..4 [x], default (1.0, 1.0, 1.0). per-channel slope
    offset: rgb each -0.5..0.5 [cv], default (0.0, 0.0, 0.0). per-channel offset
    power: rgb each 0.2..4 [x], default (1.0, 1.0, 1.0). per-channel power
    sat: num 0..4 [x], default 1.0. saturation, 1 = unchanged
  contrast()  [primary, pointwise] Log contrast around a pivot: out = (in - pivot) * amount + pivot.
    amount: num 0.3..3 [x], default 1.0. 1 = unchanged
    pivot: num 0..1 [cv], default 0.4135884. level that stays put (0.4136 = 18 % grey)
  saturation()  [primary, pointwise] Saturation: scales opponent chroma (Cb, Cr) of the working values. protect_skin 0..1 keeps skin hues (141 +- 15..40 deg) near their own saturation.
    amount: num 0..3 [x], default 1.0. 1 = unchanged, 0 = monochrome
    protect_skin: num 0..1 [x], default 0.0. 1 = skin untouched
  curve()  [primary, pointwise] Monotone cubic curve (Fritsch-Carlson, no overshoot) through points; straight lines with the end slopes beyond. channel luma keeps colour (adds the luma change to all channels); rgb applies to each channel. space log: points are ACEScct code values; display: on-screen sRGB code values.
    points: points 2..16 of [x in -0.2..1.5, y out -0.2..1.5], required. [[x, y], ...], x strictly increasing
    channel: one of luma|rgb|red|green|blue, default luma.
    space: one of log|display, default log.
  hue_vs_hue()  [primary, pointwise] Rotate selected hues. Each point [hue, shift, width] acts with a raised-cosine influence `width` degrees each side (default 60); overlapping points blend. Hue is the angle of (Cb, Cr) of the ACEScct working values, degrees: red ~123, skin ~141, orange ~150, yellow ~173, green ~206, cyan ~300, blue ~350, magenta ~60.
    points: points 1..12 of [hue deg 0..360, shift deg -90..90, width deg 5..180] (last optional), required. [[hue, shift(, width)], ...]
  hue_vs_sat()  [primary, pointwise] Saturation by hue: points [hue, gain, width]; gain 1 = unchanged. Hue is the angle of (Cb, Cr) of the ACEScct working values, degrees: red ~123, skin ~141, orange ~150, yellow ~173, green ~206, cyan ~300, blue ~350, magenta ~60.
    points: points 1..12 of [hue deg 0..360, gain 0..3, width deg 5..180] (last optional), required. [[hue, gain(, width)], ...]
  hue_vs_lum()  [primary, pointwise] Brightness by hue (cv offset, weighted by chroma so greys stay): points [hue, offset, width]. 0.03 is clearly visible. Hue is the angle of (Cb, Cr) of the ACEScct working values, degrees: red ~123, skin ~141, orange ~150, yellow ~173, green ~206, cyan ~300, blue ~350, magenta ~60.
    points: points 1..12 of [hue deg 0..360, offset cv -0.3..0.3, width deg 5..180] (last optional), required. [[hue, offset(, width)], ...]
  lum_vs_sat()  [primary, pointwise] Saturation by luma: monotone curve [[luma, gain], ...] over ACEScct luma (0.15 deep shadow, 0.41 grey, 0.6 bright, 0.75+ highlights).
    points: points 2..12 of [luma cv -0.1..1.5, gain 0..3], required. [[luma, gain], ...]
  sat_vs_sat()  [primary, pointwise] Remap opponent chroma: monotone curve [[chroma_in, chroma_out], ...] (0.05 moderate, 0.1+ strong).
    points: points 2..12 of [chroma in 0..1, chroma out 0..1], required. [[c_in, c_out], ...]
  sat_vs_lum()  [primary, pointwise] Luma by saturation: monotone curve [[chroma, offset], ...] adds offset (cv) to the luma of colours of that chroma (negative darkens saturated colours).
    points: points 2..12 of [chroma 0..1, offset cv -0.3..0.3], required. [[chroma, offset], ...]
  rgb_mixer()  [primary, pointwise] Channel mixer on the working values: out = M·in with rows red, green, blue ([1, 0, 0] etc. = unchanged); preserve_luma keeps each pixel's luma.
    red: rgb each -2..2 [x], default (1.0, 0.0, 0.0). output red = red·[r, g, b]
    green: rgb each -2..2 [x], default (0.0, 1.0, 0.0). output green = green·[r, g, b]
    blue: rgb each -2..2 [x], default (0.0, 0.0, 1.0). output blue = blue·[r, g, b]
    preserve_luma: bool, default False. add back the luma the mix changed
  density()  [primary, pointwise] Subtractive (film-like) colour density: darkens each pixel by amount times its opponent chroma, so saturated colours get deeper rather than brighter. 0.5 subtle, 1.5 strong.
    amount: num -1..2 [x], default 0.0. luma change = -amount · chroma (cv)
  hue_rotate()  [primary, pointwise] Rotates every hue by the same angle (opponent Cb / Cr plane).
    degrees: num -180..180 [deg], default 0.0. counter-clockwise on the hue circle
  vibrance()  [primary, pointwise] Saturation weighted toward muted colours: k = 1 + amount · (1 − smoothstep(0, 0.12, C)); already saturated colours move little.
    amount: num -1..1 [x], default 0.0. + richer muted colours, − calmer
  split_tone()  [primary, pointwise] Tints shadows and highlights toward two hues (opponent-plane offsets weighted by luma), balance moves the split point.
    shadow_hue: num 0..360 [deg], default 315.0. 315 teal, 141 skin / orange
    shadow_amount: num 0..0.1 [chroma], default 0.0. 0.01 subtle
    highlight_hue: num 0..360 [deg], default 141.0. hue of the highlight tint
    highlight_amount: num 0..0.1 [chroma], default 0.0. 0.01 subtle
    balance: num -0.2..0.3 [cv], default 0.0. moves the split from 18 % grey
  gamut_compress()  [transform, pointwise] Reference gamut compression (the open ACES method) on linear AP1: pulls colours outside the gamut back in along their distance from the achromatic axis, leaving colours inside threshold untouched.
    threshold: rgb each 0.5..0.99 [x], default (0.815, 0.803, 0.88). [cyan, magenta, yellow] distance where compression starts
    limit: rgb each 1.01..2 [x], default (1.147, 1.264, 1.312). [cyan, magenta, yellow] distance mapped to the gamut boundary
    power: num 1..3 [x], default 1.2. curve exponent: higher = sharper knee
  vignette()  [position, position] Darken (amount > 0) or brighten (< 0) the frame edges. 0.1 subtle, 0.3 strong.
    amount: num -0.5..0.5 [x], default 0.1. strength
    roundness: num 0..1 [x], default 1.0. 1 = circular, 0 = follows the frame shape
    softness: num 0.05..1.2 [x], default 0.6. edge softness
  grain()  [position, position] Deterministic film-like grain: value noise on a `size_px` lattice from an integer hash of (cell, frame, seed, channel), strongest in the mid-tones. Same seed + frame = the same random cells on every target (grain values within float tolerance).
    amount: num 0..1 [x], default 0.2. 0.1 fine, 0.3 heavy
    size_px: num 1..8 [px], default 1.5. grain cell size
    chroma: num 0..1 [x], default 0.3. 0 = monochrome grain, 1 = independent per channel
    seed: int 0..2.14748e+09, required. required: the random seed
  glow()  [spatial, spatial] Bloom: light above `threshold` (cv) spreads by a Gaussian of `radius_px` and is added back in linear light, `warm` tints the halo.
    threshold: num 0..1.2 [cv], default 0.6. level where glow starts (0.6 ~ 3.4 stops over grey)
    radius_px: num 1..400 [px], default 40.0. Gaussian sigma
    strength: num 0..2 [x], default 0.3. amount
    warm: num -0.5..0.5 [x], default 0.0. > 0 warmer halo
  halation()  [spatial, spatial] Film-style halation: like glow, but the halo is tinted (default red-orange) and starts lower; light scattered back from the film base round bright edges.
    threshold: num 0..1.2 [cv], default 0.55. level where halation starts
    radius_px: num 1..200 [px], default 12.0. Gaussian sigma
    strength: num 0..2 [x], default 0.3. amount
    tint: rgb each 0..1 [x], default (1.0, 0.25, 0.05). halo colour weights
  diffusion()  [spatial, spatial] Diffusion / mist filter: light from bright areas spreads into darker neighbours (adds max(blur - in, 0) in linear light); lowers local contrast round highlights.
    radius_px: num 1..200 [px], default 20.0. Gaussian sigma
    strength: num 0..1 [x], default 0.25. amount
  blur()  [spatial, spatial] Gaussian blur of the working values.
    radius_px: num 0..100 [px], default 2.0. Gaussian sigma (< 0.3 = no blur)
  sharpen()  [spatial, spatial] Unsharp mask on luma with noise coring (detail below `coring` is left alone).
    amount: num 0..2 [x], default 0.3. strength
    radius_px: num 0.3..10 [px], default 1.5. Gaussian sigma
    coring: num 0..0.05 [cv], default 0.008. detail threshold
  local_contrast()  [spatial, spatial] Wide-radius local contrast on luma, blacks protected.
    amount: num -1..1 [x], default 0.15. > 0 more, < 0 softer
    radius_px: num 5..600 [px], default 200.0. Gaussian sigma
    protect_blacks: bool, default True.
  guided_detail()  [spatial, spatial] Edge-aware detail on luma (guided filter): edges stronger than `edge` keep their shape, so no halos; amount > 0 crisper texture, < 0 smoother.
    amount: num -1..2 [x], default 0.5. > 0 more detail, < 0 smoother
    radius_px: num 1..200 [px], default 8.0. box radius of the guided filter
    edge: num 0.001..0.2 [cv], default 0.02. luma step treated as an edge (sqrt of the filter's eps)
    protect_blacks: bool, default True.
  highlights_shadows()  [spatial, spatial] Local tone from a blurred luma: highlights < 0 pulls bright areas down, shadows > 0 opens dark areas. 1.0 = 0.1 cv at full strength.
    highlights: num -3..3 [x], default 0.0. < 0 recover highlights
    shadows: num -3..3 [x], default 0.0. > 0 lift shadows
    radius_px: num 1..400 [px], default 60.0. Gaussian sigma
```
